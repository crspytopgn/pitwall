**First public preview.** Pitwall makes sim racing on SteamOS and the Steam Machine easy: it sets up your sims and wheel, then helps you drive faster.

> Pitwall hasn't been tested on real hardware yet. Please [report what works and what doesn't](https://github.com/crspytopgn/pitwall/issues/new/choose); every report helps.

## Downloads

| File | For |
|---|---|
| `Pitwall-0.1.0.zip` | The **Decky plugin**: Decky → cog → Developer mode → Install Plugin from ZIP File. [Guide](https://github.com/crspytopgn/pitwall/blob/main/docs/install.md) |
| `Pitwall-standalone-0.1.0.tar.gz` | **Standalone**, no Decky needed: extract, then run `./install.sh` in Desktop Mode. [Guide](https://github.com/crspytopgn/pitwall/blob/main/docs/standalone.md) |

New Steam Machine? Start with the [day-one guide](https://github.com/crspytopgn/pitwall/blob/main/docs/day-one.md).

## What's in it

- **Auto setup** for your device and wheel, and a **game guide** for 27 sims: whether each runs on SteamOS, setup steps, in-game force feedback settings and known issues, with live ratings from Valve, ProtonDB and Are We Anti-Cheat Yet
- **Telemetry** from BeamNG, Live for Speed, Forza, DiRT, F1 21–23, Assetto Corsa, ACC, AC EVO, AMS2, Project CARS 2, rFactor 2, Le Mans Ultimate, RaceRoom and the SCS truck sims, including a one-tap telemetry bridge for shared-memory sims
- **Wheel buttons**: see what every button does in Steam and in the game, live and on your phone; move around Steam's menus with your wheel; BeamNG.drive's buttons set up for you
- **Graphics tuning** for the Steam Machine: a graphics level per game, a steady frame cap, and automatic adjustment after each session (Assetto Corsa's settings changed directly; preset advice for other games)
- **Wheel control and profiles** per game and per car: MOZA (all bases), Logitech, Fanatec, Thrustmaster; rev lights on MOZA and Logitech; clear messages when a MOZA base isn't usable, such as an R3 still in Xbox mode
- **Force feedback setup**: which effects your driver supports, a gentle test pull, and on SteamOS a one-tap install of the community driver your wheel needs, with a reinstall prompt after SteamOS updates
- **Force feedback tuning**: sourced presets and a "what feels wrong?" tuner with undo
- **Phone dashboard** over Wi-Fi with five layouts (shift lights, gear, delta, times, fuel, tyres, track map, voice callouts)
- **Coaching**, **fuel and tyre strategy**, **performance checks**, an optional **engineer debrief**, **update checks** for installed drivers and the bridge, and **one-tap diagnostics** for bug reports

Full list in the [changelog](https://github.com/crspytopgn/pitwall/blob/main/CHANGELOG.md). Pitwall builds on the Linux sim racing community's work; see the [credits](https://github.com/crspytopgn/pitwall/blob/main/CREDITS.md).
